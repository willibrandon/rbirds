# Evidence

What has been compared, where, and with what result. Every claim here names the test that makes it; `tools/verify.sh` reruns the local gates. Reference: cbirds 1.4.0, commit `cc446fc3cb80733371c62676533adcac2fc10002`, verified file by file against [the manifest](../reference-manifest.json) by `tools/reference.sh`.

The x86_64 macOS row runs under translation and the x86_64 Linux row under emulation; both are evidence of the bindings and arithmetic on those targets, not of native execution. PORTING.md §6 requires native CI runs of those two before a release claim.

## Reference baselines (P0)

- The pinned reference's own `make test` (all seven suites, 112 tests) passes on macOS arm64 (Apple clang) and on Linux arm64 and x86_64 (GCC 12.2, glibc 2.36), the latter including its glibc `rand()` comparison.
- Observing the C suite does not change it: `tools/oracle/boids_suite.c` runs the unmodified `tests/boids_test.c` and dumps the global state as each test is entered, and the suite still passes under observation on every target above.
- The embedded sprite is byte-identical to `matrix.png` and to the array in `sprite_png.h`.

## Numerical findings

Both are properties of the canonical C build that the port reproduces deliberately ([design](../DESIGN.md) §5):

- [`fma-sites.txt`](fma-sites.txt): the 92 sites where Apple clang contracts `a*b+c` (generated from the reference's debug info by `tools/oracle/fma-sites.sh`). `tests/fma_sites.rs` holds the Rust `fma:` tags to it exactly and regenerates it on arm64 macOS.
- [`trig-sites.txt`](trig-sites.txt): every sine and cosine in the `-O3` build is a fused `__sincos_stret` call (generated by `tools/oracle/trig-sites.sh`). On arm64 that routine differs from separate calls by one ulp for 24,288 of 2×10⁷ arguments; on x86_64 macOS and in glibc (whose `sincos` GCC uses the same way) fused and separate results agree for all 2×10⁷.

## Gates

- Dependency graph: `cargo tree --edges all --target all --all-features` and `cargo metadata` show one package, `rbirds`, with no dependencies; the manifest has no dependency tables.
- Linkage: the macOS release binary links only `/usr/lib/libSystem.B.dylib`.
- `unsafe` appears only under `src/platform/`, each block with its safety argument.
- `cargo fmt --check` and `cargo clippy --all-targets --all-features -- -D warnings` are clean.
- `tests/inventory.rs` rediscovers the 112 C test calls and checks every mapping; `tools/verify.sh` checks each mapped test is run.
