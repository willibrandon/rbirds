These time building frames with --bench, with no terminal. How frames reach
a terminal is in live-2026-09-26-macos-arm64.txt.

The big-* workloads are big-flock mode, which has no C equivalent. They run
on its threads, half the cores (6 here). Up to 4096 birds each must give
the same bytes a frame as the single-thread workload named beside it.

while other work ran on the host, and were repeated; the repeat is used here.
